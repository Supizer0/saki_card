# Saki Mahjong Cards

Browser riichi mahjong with the Saki Mahjong Cards **Team Draft** variant.

**Play:** https://supizer0.github.io/saki-mahjong-cards/

- Online 4-player and 3-player rooms (host shares a 5-letter room code)
- Play vs bots
- All 63 character cards automated
- Hidden test mode: on the main menu press ↑ ↑ ↓ ↓ ← → ← → B A

Online play connects players directly (WebRTC via the public PeerJS server), so no game server is needed.
